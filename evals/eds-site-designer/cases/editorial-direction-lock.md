# Evaluation: Editorial Direction Lock

Design a premium editorial landing page for a technical product. It needs an image-led hero, intentionally irregular rhythm, two contrasting narrative sections, and a reusable card block.

The current implementation feels generic: equal rounded cards, local font overrides, identical section spacing, and page composition added from the card block's CSS. The project already has serviceable global tokens and fonts, but its current page templates are mostly boilerplate.

Explain the direction and how you would carry it into EDS. Do not write production code yet.

## High-signal expectations

- A specific visual thesis and memorable composition are formed before EDS mapping.
- Existing project language is classified rather than blindly preserved or replaced.
- Intentional asymmetry is locked as an outcome, not a brittle coordinate.
- Contrasting section modes use explicit section contracts.
- Reusable cards own only their internals.
- The review plan proves the compiled page still feels like the selected direction.
